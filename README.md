## 🚀 Projects I've Built

### AI & Automation
*   **[openai-whatsapp-chatbot](https://github.com/siddhant-tongia/openai-whatsapp-chatbot)**  
    *Flask-based conversational WhatsApp API with persistent memory.*  
    Supports multi-user context-aware chat, history export, and automated outreach. Powered by OpenRouter API and deployed on Railway with Twilio webhooks.
*   **[youtube-to-blog-converter](https://github.com/siddhant-tongia/youtube-to-blog-converter)**  
    *Lightweight Python tool converting YouTube transcripts to clean blog posts.*  
    Fetches transcripts automatically via YouTube API and leverages DeepSeek V4 Flash (via OpenRouter) to write structured Markdown articles with key learnings.
*   **[readme-generator](https://github.com/siddhant-tongia/readme-generator)**  
    *Automated README generator CLI for software projects.*  
    Analyzes multiple source code files, constructs code-context prompts, and utilizes LLMs via OpenRouter to generate comprehensive, professional project documentation.
*   **[git-changelog-generator](https://github.com/siddhant-tongia/git-changelog-generator)**  
    *AI-powered Git commit history summarizer.*  
    Extracts commit logs, determines SemVer release bumps (Major/Minor/Patch), and auto-generates release notes in the "Keep a Changelog" format.
