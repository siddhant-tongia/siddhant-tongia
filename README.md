## 🚀 Projects

### 🤖 [openai-whatsapp-chatbot](https://github.com/siddhant-tongia/openai-whatsapp-chatbot)
> **Flask-based conversational WhatsApp API with persistent memory.**
- Deployed on **Railway**, powered by **OpenRouter API** and integrated with **Twilio API** for WhatsApp.
- Implements multi-user conversation state tracking, history export, and chatbot-initiated outbound messages.
- *Tech Stack:* Flask, Python, Twilio, JSON, Railway, OpenRouter API.

### 🔍 [rag-from-scratch](https://github.com/siddhant-tongia/rag-from-scratch)
> **Step-by-step implementation of Retrieval-Augmented Generation pipelines.**
- Jupyter Notebooks covering RAG basics, query routing, query transformations, and structured query construction.
- Explores routing mechanisms and query reformulation to maximize LLM retrieval precision.
- *Tech Stack:* Python, Jupyter Notebooks, LLMs, Vector Search concepts.

### 📄 [git-changelog-generator](https://github.com/siddhant-tongia/git-changelog-generator)
> **AI-powered git commit summarizer and Semantic Version bump calculator.**
- Python CLI that extracts commit history using git subprocesses and generates structured markdown changelogs.
- Automatically determines release bump level (Major/Minor/Patch) following SemVer rules.
- *Tech Stack:* Python, Git integration, OpenAI SDK, OpenRouter, python-dotenv.

### 📚 [DSA-C-Plus-Plus](https://github.com/siddhant-tongia/DSA-C-Plus-Plus)
> **My exhaustive DSA learning archive tracking Apna College masterclass (126 videos).**
- Covers arrays, sorting/searching algorithms, binary search on answers, 2D arrays, and strings.
- Contains implementations of key algorithms to build strong problem-solving fundamentals.
- *Tech Stack:* C++, STL.

### 📊 [Data-Analysis-With-Python](https://github.com/siddhant-tongia/Data-Analysis-With-Python)
